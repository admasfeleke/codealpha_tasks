## 🧹 Preprocessing & Feature Engineering
- **Outlier removal:** dropped 1 extreme row (Toyota Land Cruiser, present price 92.6 lakhs — 3× the next car, unrepresentative of the dealer's mainstream inventory); 300 cars remain
- **Car_Age** engineered from `Year` (newer = pricier)
- **Brand** extracted from `Car_Name` (captures brand goodwill); rare brands (<7 listings) grouped as `other`
- **Kms_per_Year** engineered (usage intensity beats raw mileage)
- One-hot encoding for `Fuel_Type`, `Selling_type`, `Transmission`, `Brand`
- Dropped leaky/redundant columns (`Car_Name`, `Year`, raw depreciation)

## 📊 Model Results (80/20 split, seed 42)

| Model | Test R² | Test MAE | Test RMSE | 5-Fold CV MAE |
|-------|---------|----------|-----------|----------------|
| **Random Forest** | **0.9480** | **0.666 lakhs** | 1.077 lakhs | **0.872 ± 0.660** |
| Ridge Regression | 0.8682 | 1.205 lakhs | 1.715 lakhs | 1.383 ± 0.447 |
| Linear Regression | 0.8657 | 1.203 lakhs | 1.732 lakhs | 1.400 ± 0.448 |

**Random Forest wins decisively** — ~45% lower error than linear models, and cross-validation MAE (0.87) is consistent with test MAE (0.67), showing the model generalizes rather than memorizes.

### Feature importance (Random Forest)
1. **Present_Price (0.850)** — the dealer's current showroom price dominates
2. **Car_Age (0.078)** — depreciation with age
3. **Driven_kms (0.029)** — usage wear
4. Kms_per_Year, Transmission_Automatic, fuel type — minor effects

## 💡 Real-World Takeaways
- A dealer can price cars within **±0.67 lakhs (~₹67k)** using just 8 objective features
- **Present price is the anchor** — resale value is mostly a ratio of showroom price, adjusted for age and usage
- Individual sellers get systematically lower prices than dealers — transparency gap ML pricing could close
